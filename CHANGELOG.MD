# Changelog

Todas as mudanças relevantes do projeto serão documentadas neste arquivo.

---

## [v3.0] - 2026-11-06

### Adicionado

- Interface Web responsiva
- ESP8266 NodeMCU
- Sensor DHT22
- Controle de aquecimento por relé
- Controle por histerese
- Armazenamento de configuração em EEPROM
- Dashboard em tempo real via AJAX
- Monitoramento de temperatura
- Monitoramento de umidade relativa
- Cálculo de umidade absoluta
- Tema escuro
- Hostname local via mDNS
- Exibição de RSSI Wi‑Fi
- Exibição de uptime
- Histórico de 12 horas
- Amostragem a cada 10 minutos
- Barras de progresso para todos os parâmetros

### Alterado

- Migração do display TFT para interface Web
- Mudança do nome do projeto de DryFilaBox para DryBox

### Corrigido

- Atualização da interface sem recarregamento da página
- Problemas de codificação UTF‑8
- Problemas de JavaScript na atualização AJAX
